# Saheer Khan — Portfolio

Personal portfolio website showcasing my work as a **web developer**, **AI agent builder**, and **cybersecurity learner**.

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no bloat.

## Highlights

- **SEO-optimized** with structured data, Open Graph, Twitter Cards
- **Fast** — inline CSS, preconnect hints, minimal JS
- **Accessible** — ARIA labels, semantic HTML, proper heading hierarchy
- **Responsive** — mobile-first design across all breakpoints
- Dark theme with custom cursor, loader animations, scroll reveals

## Tech Stack

HTML5 · CSS3 · JavaScript · Font Awesome · Google Fonts (Syne, DM Sans)
